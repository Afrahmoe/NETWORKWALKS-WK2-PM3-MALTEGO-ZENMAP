## Project Overview

This project involved performing two practical cybersecurity activities: footprinting and network scanning.

The first activity used Maltego on Kali Linux to conduct reconnaissance against the `networkwalks.com` domain and identify publicly available information.

The second activity used Zenmap (Nmap GUI) to scan my own local LAN, identify live hosts, examine their IP and MAC addresses, and visualize the network topology.

The purpose of these exercises was to understand how information gathering and network discovery contribute to the early phases of penetration testing.

| Tool | Purpose |

## Tasks Completed

### 1. WK2-PM3 — Maltego: Footprinting & Reconnaissance

- Installed and configured Maltego on Kali Linux.
- Completed the Maltego registration process.
- Created a Domain entity for `networkwalks.com`.
- Executed email-related transforms.
- Identified an associated email address through the transform results.

### 2. WK2-PM5 — Zenmap: Network Scanning

- Used the `ifconfig` command to identify my local IP address and subnet.
- Configured Zenmap with my local LAN subnet.
- Performed a Ping Scan to identify live hosts.
- Identified two live hosts, including my own PC.
- Examined the IP and MAC addresses returned by the scan.
- Viewed the network topology using the Topology tab.
- Enabled and reviewed the topology legend.
- Exported the topology graphic as a PDF.

## Key Observations

**Maltego:**
- An email address associated with the target domain was returned by an email-related transform.

**Zenmap:**
- Two live hosts were identified on my local LAN.
- IP addresses and MAC addresses were displayed in the scan results.
- A graphical representation of the discovered network was generated and exported.
